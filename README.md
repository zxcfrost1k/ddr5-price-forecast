# Анализ цен на оперативную память DDR5

Материалы практической работы № 2. Исходный CSV содержит 7 116 очищенных ценовых наблюдений из среза PCstonks / DNS от 17.11.2026. Одна строка описывает один артикул и дату однозначного предложения в наличии. Цена указана в рублях за комплект. Источник — https://pcstonks.com/catalog/.

Для повторного разбиения и разведочного анализа из корня репозитория выполните:

```sh
python3 scripts/prepare_data.py
```

Достаточно Python 3.10 или новее и его стандартной библиотеки. Скрипт читает `data/raw/observations.csv` без записи в него. Контрольные суммы и диапазоны дат указаны в `data/manifest.json`. Скрипт сохраняет исходную часть в `data/initial/initial.csv`, а четыре хронологические порции в `data/incoming/`. Записи одной даты целиком принадлежат одной части.

Отчёт `reports/eda_initial.json` рассчитан только по исходной части. В `reports/eda_target_7d.csv` сохранены пары с фактическими ценами на обе даты. Для проверки используется ровно семь календарных дней. Исходная и будущие даты пары находятся внутри исходной части. Порции предназначены для имитации поступления данных из архива. Планируемый рабочий режим использует ежедневные обновления.
