# Анализ цен на оперативную память DDR5

Исходный срез PCstonks / DNS содержит 7 116 очищенных наблюдений по 236 артикулам DDR5. Одна строка описывает однозначную цену комплекта в наличии на дату события. Цена указана в рублях. Источник: https://pcstonks.com/catalog/.

## Версии

- `pr1` — архитектурные решения, схемы и пересчёт недельного базового прогноза.
- `pr2` — хронологические порции, разведочный анализ, статистические проверки и схемы проектирования системы.

## Воспроизведение расчётов

Из корня репозитория выполните две команды. Для них достаточно Python 3.10+ и стандартной библиотеки.

```sh
python3 scripts/summarize_snapshot.py
python3 scripts/prepare_data.py
```

Первая команда описывает полный срез и пересчитывает MAE правила сохранения текущей цены на тесте. Вторая читает `data/raw/observations.csv` без записи в него, сохраняет раннюю часть в `data/initial/initial.csv` и четыре последующие порции в `data/incoming/`. Записи одной даты принадлежат одной части. Периоды и SHA-256 фиксируются в `data/manifest.json`. Порции имитируют обновления из архива. Проектируемый рабочий режим использует суточные обновления.

Отчёт `reports/eda_initial.json` и пары `reports/eda_target_7d.csv` рассчитаны внутри исходной части. Пары требуют однозначной цены на обе даты, разнесённые ровно на семь дней. В статистических проверках применяется одна агрегированная оценка на бренд или артикул, односторонние критерии и поправка Холма на четыре гипотезы. Перестановки используют 9 999 повторов и фиксированное начальное число 42. Независимость групп предполагается для формального расчёта; общие рыночные факторы могут связывать группы.

## Диаграммы

В `diagrams/` находятся готовые рисунки в PNG и редактируемый исходник `render.py`. Чтобы пересобрать рисунки, установите Pillow и запустите `python3 diagrams/render.py`. Переменная `RAM_DIAGRAM_FONTS` задаёт каталог с файлами `Times New Roman.ttf` и `Times New Roman Bold.ttf`. Скрипт использует данные из `reports/eda_target_7d.csv`.
